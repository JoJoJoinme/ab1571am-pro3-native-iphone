# AB1571AM Pro 3 原生 iPhone 功能复现材料

这份材料记录一副第三方 Pro 3 耳机的固件实验，并提供精确镜像校验、单字节补丁生成器、升级包生成器和 Android 辅助程序源码。样本构建为 `2026/10/12 15:44:12 GMT +08:00`，升级版本为 `V310.1.865.11`。

设备所有者已确认原生降噪／通透控制、耳机柄与系统状态同步可用。设备信息上报调整后，普通重连未恢复顶部卡片；在 iPhone 忽略设备并重新配对后，顶部图片、卡片和连接弹窗出现。

**已知未解决问题：充电仓电量通常只在取出耳机、配对时出现，其他时候大多不显示，与 Pro 2 不同。**不能把卡片出现等同于电量行为已经完整恢复。

只有精确哈希匹配的镜像才被工具接受。同芯片、同外壳、相同版本文字都不能代替这个检查。不要删除校验，也不要使用另一副耳机的备份。

## 内容

| 路径 | 用途 |
| --- | --- |
| `tools/firmware_tool.py` | 离线核对双耳备份并生成升级包与原版 MCU 回退包 |
| `tools/phone_file.py` | 以二进制方式导出备份和传入升级包，避免文本转码 |
| `tools/fetch_sdk.py` | 获取并核对指定版本的参考库 |
| `tools/build_helpers.py` | 构建绑定自己耳机地址的辅助程序，不安装、不连接设备 |
| `source/readonly` | 只读识别、备份和实际 MCU 哈希查询 |
| `source/fota` | 双耳检查、暂存、独立哈希核对和单次提交 |
| `source/metadata` | 仅调整本构建设备信息上报标志，保留缓存相邻字节 |

本次硬件流程在 Windows、一加 Android 13 与 iPhone 上完成。转交源码包含新增目标绑定和 MCU 哈希检查，已通过构建和离线校验，没有对工作中的耳机做重复刷写。实机回退、断电恢复、跨设备适用性和长期稳定性没有得到验证。

## 快速离线检查

```powershell
python .\tools\firmware_tool.py check .\own\connected.bin
```

完整生成与刷写必须按指南执行，先保存自己两耳的完整备份和各自清单，再生成候选包。未知镜像应停止分析，不能使用本工具强制刷写。
